## 1. 已确认的单人决策

- 只有你一个人开发，不再有 A/B/C 三个 owner、三个 worktree、三人会签。
- 编程模式改为：**一个 workspace、一个活跃 Qoder owner 会话、一个检查点一次**；审查用只读 review 子代理。
- 任务按**纵向切片 + 检查点**推进，不按时间同步；完成检查点就停止、跑测试、写进度包、自检、提交。
- 先做 MVP：本地 Spring Boot 2.7 + Vue3，0 行、纯前端、回放、工作台、L1、sourcemap、IDEA/JAR 接入。
- React/Webpack、Tomcat WAR/SSM、L2、云端按 S7–S10 逐步加；不同时开工。
- 不做独立原型设计图；工作台直接实现。
- 云端首发只接收 Boot JAR；WAR 本地完整，云端 P4 再开；强隔离未达标不开放任意上传。
- 回放是事件级图 + 数据/UI 摘要，不重新执行程序。

## 3. 单人编程模式（Qoder）

### 3.1 工作区与分支

- 一个 Qoder workspace，指向单人工作目录；不建 A/B/C worktree。
- 推荐 `main` + 短分支 `feat/Sx-*`；每个检查点至少一个可回滚 commit/tag。
- 同一时间只开一个会写代码的 owner 会话；审查另开只读 review 会话/子代理。
- 不按天/周判断是否继续；完成检查点才继续。

### 3.2 每个检查点的会话流程

1. 新会话或压缩上下文；只读 `README.md`、`SOLO-PLAN.md`、主计划对应章节、当前契约/fixture。
2. 只做一个检查点 `Sx`；先给计划/测试，高风险先 plan。
3. 写代码 + 测试 + demo；不要用“AI 说完成”当验收。
4. 到检查点：**停止继续修改**，跑测试，写进度包，review 子代理自查。
5. 更新 `SOLO-PLAN.md`/契约，提交/tag；再开 `Sx+1`。
6. 未通过检查点不跨到下一个；被阻塞就切测试/fixture/文档/性能基线。

### 3.3 会话开场模板

```text
你是 TraceBoard 的单人开发结对助手。当前只做检查点 Sx。
先读 docs/plans/README.md、docs/plans/SOLO-PLAN.md、主计划对应章节、当前契约/fixture。
写入范围：本检查点相关文件；不要改其他模块/契约。
要求：先给计划/测试，再改代码；每次改动跑验收；不自动下载 GitHub/无镜像资源。
到达 Sx 检查点后停止继续修改，输出进度包并等待我确认，不要自动跨到 Sx+1。
```

## 5. 检查点停止与自检

到达任一检查点，必须：

1. 停止继续修改，跑验收测试/demo。
2. 写进度包：
   ```text
   CHECKPOINT: S2
   STATUS: done | partial | blocked
   EVIDENCE: 命令/测试/demo/截图/fixture
   CHANGED: 文件/事件字段/API/契约
   RISK: 未采集/性能/兼容/隐私
   NEXT: S3
   ```
3. 用只读 review 子代理检查：契约是否破坏、secret、静默缺口、回放是否只读、性能。
4. 更新计划/契约，提交/tag。
5. 自检通过才进入下一个检查点；没有队友会签，但规则本身是硬门。

## 6. Git / Qoder 规则

- `git init` + `.gitignore`（`target/`、`logs/`、`work/`、运行时数据、密钥）。
- 一个 `main` + 短分支；每个检查点一个 commit/tag；不长期保留大分支。
- 一个 owner 会话写代码；review 会话只读；不让两个 Qoder 会话同时改同一文件。
- 高风险改动先 plan；写完跑测试；生成代码不手改。
- 不把真实 secret/客户数据放进 prompt/fixture；默认脱敏。
- GitHub/国内无镜像资源：给官方链接/版本/放置位置/校验，由你下载；不自动换第三方镜像。
- 不依赖外部 CDN/在线字体；本地原型/工作台断网可用。

## 8. Definition of Done

- 有对应验收用例；至少一个正常 + 一个“未采集/错误”路径。
- 不破坏 main 的 demo；schema/API 变更有兼容测试。
- 无 secret/真实数据进入日志、fixture、prompt；默认脱敏。
- 性能：L0/L1 不超主计划目标；前端构建增量可测。
- 有 review；文档/契约更新；可回滚。
- 未验证的能力标“仅本地/基础/暂不支持”，不写成“已支持”。

## 9. 当前不做

- 不创建业务代码，直到你明确说“开始开发”。
- 不做三人 worktree/三人会签/每日或每周同步。
- 不做独立原型图/HTML/PNG。
- 不做像素级页面回放。
- 云端首发不收 WAR；WAR 本地完整，云端后置。
- 不把未测试的环境/版本标成“支持”。
