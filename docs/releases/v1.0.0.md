# TraceBoard 1.0.0

TraceBoard 1.0.0 是本地、只读的 Java 全链路调试工具正式版。

## 下载

- `TraceBoard-1.0.0-win-x64-portable.zip`
- `.sha256` 校验文件

## 环境

- JDK 21：启动 TraceBoard。
- JDK 8 / 17 / 21：运行被调试的 Spring Boot 应用。
- Windows 10/11；仅使用本机回环端口。

## 快速开始

```bat
TraceBoard.cmd run --jar "C:\path\to\your-app.jar" --java "C:\path\to\jdk\bin\java.exe"
```

默认端口为应用 `8080`、collector `8601`、工作台 `5173`，可分别用 `--port`、`--collector-port`、`--ui-port` 自定义。启动后打开 `http://127.0.0.1:5173/`：

- 「我的应用」内嵌目标 JAR；
- 「追踪台」查看 Controller / Service / Mapper / SQL、参数和请求体字段。

## 支持范围

- Spring Boot 2.x / 3.x 可执行 JAR；
- Spring MVC + MyBatis；
- JDK 8 / 17 / 21；
- 可选浏览器 SDK 实现点击与后端 EXACT 关联。

不支持 WebFlux、JPA/Hibernate SQL、外部 Tomcat WAR、动态 attach 和行级局部变量。

## 站点状态

静态站点采用手动 Pages 发布，等待账号切换后重新构建 `site/traceboard/dist`；1.0.0 源码清理阶段不提交旧 dist，普通代码推送不会自动部署。

## 边界

- 仅限本地开发；无鉴权/TLS/云端上传。
- 不采集行级局部变量、SQL 文本、原始响应体、Cookie。
- 采集到的值保存在本机日志/内存中，不要连接生产敏感数据。
